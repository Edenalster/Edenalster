## 🚀 Featured Projects

### 🤖 [Career Coach AI](https://github.com/Edenalster/career-coach-AI)

An AI-powered CV analysis and interview preparation assistant focused on generating evidence-grounded recommendations.

- Developed a LangGraph workflow for CV gap analysis, CV tailoring, and interview preparation.
- Implemented Pydantic validation and an LLM judge to verify generated claims against source CV content.
- Evaluated the judge using 32 manually labeled cases.
- Added automated tests and GitHub Actions CI.
- Containerized the application with Docker and built a Gradio interface.

**Tech Stack:** Python · LangGraph · Pydantic · LLM APIs · pytest · Docker · GitHub Actions · Gradio
